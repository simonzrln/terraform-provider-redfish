# Redfish Provider (AMI MegaRAC)

A slim fork of [dell/terraform-provider-redfish](https://github.com/dell/terraform-provider-redfish)
(v1.6.2) for servers whose BMC runs **AMI MegaRAC** firmware, such as ASRock Rack boards with an
AST2600. The iDRAC dependencies are removed, the standard Redfish resources stay, and the
`redfish_ami_*` resources cover what AMI exposes only through the private REST API behind its web
UI: fan modes, fan curves, fan assignments, sensor thresholds and services.

## Tested hardware

Only tested on an ASRock Rack **B650D4U**, BMC firmware 6.09 (AST2600), BIOS 22.10. AMI firmware
differs between boards and versions; other boards may need changes.

## Conventions

* Settings always exist on the BMC, so **destroy only removes a resource from state**. It never
  resets the hardware.
* Only configured attributes are managed. Unset optional attributes are read but never written.
* After every write the provider reads the value back and **fails if the BMC did not store it**.
  AMI firmware often acknowledges a write it silently ignores, for example fan thresholds that
  snap to 400-RPM steps.
* `redfish_bios` never reboots the host unless `reset_type` is set. Without it, BIOS changes stay
  pending (`pending_reboot = true`) until the next reboot. `redfish_power` and
  `redfish_manager_reset` act on the host or BMC as soon as they are applied.
* A BMC cold start (AC loss) resets fan modes and thresholds. Run `terraform plan` regularly to
  catch it.

BIOS attribute names and values are the raw Redfish names (`CbsCpuSvmEnableRPL`), not the
setup-menu labels. Map them with the attribute registry linked from `/redfish/v1/Registries`.

## Example Usage

```terraform
terraform {
  required_providers {
    redfish = { source = "simonzrln/redfish" }
  }
}

variable "bmc_password" {
  type      = string
  sensitive = true
}

# One entry per BMC; resources pick it with redfish_server { redfish_alias = "bmc" }.
provider "redfish" {
  redfish_servers = {
    bmc = {
      user         = "admin"
      password     = var.bmc_password
      endpoint     = "https://192.0.2.10"
      ssl_insecure = true # AMI ships a self-signed certificate
    }
  }
}
```
